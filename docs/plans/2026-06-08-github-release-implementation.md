# GitHub Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a repeatable GitHub release flow that builds unsigned macOS DMG installers for both `x64` and `arm64` from a pushed `v*` tag.

**Architecture:** Use `electron-builder` on top of the existing renderer/main build pipeline. Add packaging metadata and scripts in `package.json`, then add a dedicated GitHub Actions workflow that builds each architecture on a native macOS runner and publishes both artifacts to a GitHub Release.

**Tech Stack:** Electron, React, TypeScript, Bun, GitHub Actions, electron-builder.

---

### Task 2: Add GitHub release workflow

**Files:**
- Create: `.github/workflows/release.yml`

**Step 1: Write workflow**

- Trigger on pushed tags matching `v*`.
- Build `x64` on `macos-13` and `arm64` on `macos-14`.
- Run install, typecheck, tests, and packaging in each matrix leg.
- Upload per-arch DMG artifacts.
- Publish both artifacts in a GitHub Release in a final job.

**Step 2: Validate workflow syntax by inspection and local YAML readback**

Expected: matrix fields, artifact names, and release file globs line up with builder output names.
